# 🎮 Крестики-Нолики 2.0 (Ultimate Tic-Tac-Toe)

## Описание игры

Это продвинутая версия классических крестиков-ноликов с полем 9×9, разделённым на 9 полей 3×3.

### Правила:
1. Игроки ходят по очереди (X начинает первым)
2. Когда вы ставите знак в ячейку малого поля 3×3, это определяет, в каком поле 3×3 должен ходить следующий игрок
3. Например: если вы поставили крестик в **верхнюю левую** ячейку любого малого поля, соперник должен ходить в **верхнем левом** большом поле 3×3
4. Если следующее поле уже заполнено или выиграно, можно ходить в любое доступное поле
5. Победа в малом поле отмечается цветом и засчитывается как один знак на большой доске
6. Для победы нужно выиграть 3 больших поля в ряд (по горизонтали, вертикали или диагонали)

## 📱 Как установить в Telegram

### Шаг 1: Создайте бота в Telegram
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например, "Крестики-Нолики 2.0")
4. Введите username для бота (должен заканчиваться на `bot`, например `ultimate_tictactoe_bot`)
5. BotFather выдаст вам API токен - сохраните его

### Шаг 2: Настройте Web App
1. Отправьте @BotFather команду `/mybots`
2. Выберите вашего бота
3. Нажмите "Bot Settings" → "Menu Button" → "Configure Menu Button"
4. Отправьте ссылку на ваш сайт (см. ниже "Хостинг")
5. Введите название кнопки (например, "Играть")

### Шаг 3: Хостинг приложения

#### Вариант A: GitHub Pages (Бесплатно)
1. Создайте репозиторий на GitHub
2. Загрузите файл `index.html`
3. Перейдите в Settings → Pages
4. Включите GitHub Pages для ветки `main`
5. Ваш сайт будет доступен по адресу: `https://ваш-username.github.io/имя-репозитория/`

#### Вариант B: Netlify (Бесплатно)
1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку с `index.html` в окно браузера
3. Сайт будет опубликован мгновенно
4. Вы получите ссылку вида: `https://random-name.netlify.app`

#### Вариант C: Vercel (Бесплатно)
1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Импортируйте проект из GitHub или загрузите файлы
3. Сайт будет автоматически развёрнут

### Шаг 4: Добавьте ссылку в бота
1. В @BotFather используйте команду `/setmenubutton`
2. Выберите вашего бота
3. Отправьте URL вашего сайта
4. Готово! Теперь пользователи могут запускать игру через меню бота

## 📲 Как открыть как мобильное приложение (PWA)

### На Android (Chrome):
1. Откройте сайт в браузере Chrome
2. Нажмите на три точки (меню)
3. Выберите "Добавить на главный экран"
4. Подтвердите добавление
5. Иконка появится на главном экране как обычное приложение

### На iOS (Safari):
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Прокрутите вниз и выберите "На экран «Домой»"
4. Подтвердите добавление
5. Иконка появится на главном экране

## 🤖 Как опубликовать в Google Play (Android)

### Подготовка:
1. **Создайте аккаунт разработчика**
   - Зарегистрируйтесь в [Google Play Console](https://play.google.com/console)
   - Оплатите единовременный взнос $25

2. **Подготовьте материалы:**
   - Иконка приложения (512×512 px)
   - Скриншоты (минимум 2, 1080×1920 px)
   - Описание приложения
   - Политика конфиденциальности

### Создание APK/TWA:

#### Вариант A: Bubblewrap (рекомендуется для PWA)
```bash
# Установите Node.js
npm install -g @bubblewrap/cli
bubblewrap init --manifest https://ваш-сайт.com/manifest.json
bubblewrap build
```

#### Вариант B: WebView приложение
1. Создайте проект в Android Studio
2. Используйте WebView для отображения сайта
3. Соберите APK через Build → Generate Signed Bundle/APK

### Публикация:
1. Войдите в Google Play Console
2. Создайте новое приложение
3. Заполните все разделы (описание, скриншоты и т.д.)
4. Загрузите APK/AAB файл
5. Отправьте на модерацию (обычно 1-3 дня)

## 🍎 Как опубликовать в App Store (iOS)

### Подготовка:
1. **Членство в Apple Developer Program**
   - Зарегистрируйтесь на [developer.apple.com](https://developer.apple.com)
   - Оплатите ежегодный взнос $99

2. **Необходимые инструменты:**
   - Mac компьютер
   - Xcode (бесплатно из App Store)
   - Сертификаты и профили provisioning

### Создание приложения:

#### Вариант A: PWABuilder (простой способ)
1. Перейдите на [pwabuilder.com](https://pwabuilder.com)
2. Введите URL вашего сайта
3. Скачайте пакет для iOS
4. Откройте в Xcode и настройте

#### Вариант B: Native WebView
1. Создайте новый проект в Xcode
2. Добавьте WKWebView
3. Настройте Info.plist для разрешения загрузки вашего URL
4. Соберите архив (Product → Archive)

### Публикация:
1. Откройте [App Store Connect](https://appstoreconnect.apple.com)
2. Создайте новое приложение
3. Заполните метаданные (название, описание, скриншоты)
4. Загрузите сборку через Xcode или Transporter
5. Отправьте на проверку (обычно 1-2 дня)
